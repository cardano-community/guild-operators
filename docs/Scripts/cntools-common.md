# CNTools common tasks

The step-by-step wallet and pool workflows documented for CNTools 13 do not
apply to the rewritten CNTools 14 framework.

!!! warning "Operational actions are not implemented yet"
    Version 14.0.0 currently provides the Gum interface, navigation tree,
    logging, runtime-mode boundaries, and Guild Deploy update flow. Wallet,
    pool, transaction, governance, and query actions are placeholders.

Operational guides will be added here as the corresponding modular actions
are implemented and tested. Until then, use reviewed Cardano tooling and
procedures directly; do not treat a visible CNTools menu entry as a supported
workflow.

For installation, modes, and the current interface contract, see the
[CNTools guide](cntools.md). Release progress is recorded in the
[CNTools changelog](cntools-changelog.md).
