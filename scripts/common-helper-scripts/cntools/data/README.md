# Recovery phrase words

The English recovery phrase word list is included with CNTools so word-by-word
mnemonic import is available offline. The list contains the 2,048 standard
BIP39 English words.

Source: [BIP39 English word list](https://github.com/bitcoin/bips/blob/2692bed47977d247a9acff610e20ebd7abb7d906b/bip-0039/english.txt).
